# IronPulse Gym

Plataforma web de gestión de membresías, clases y entrenamientos para gimnasio.

## Herramientas
- Node.js 20 o superior
- npm 10 o superior
- Git 2.40 o superior
- Jest (pruebas unitarias)

## Instalación
    git clone https://github.com/USUARIO/ironpulse-gym.git
    cd ironpulse-gym
    npm install

## Ejecutar pruebas
    npm test

## Flujo de trabajo
Ramas feature/nombre-descripcion desde main, commits atómicos y Pull Request hacia main.
